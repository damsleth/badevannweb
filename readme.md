# badevannweb

badewannweb er en web frontend til npm-pakken [badevann](npmjs.com/package/badevann).  
`badevann` henter mesteparten av dataene sine fra [YR](yr.no).  
Til gjengjeld har ikke yr laget noe badevann-sentrisk grensesnitt på sine nettsider,  
men lener seg på at brukeren vet hvilket sted hen vi ha info om, og presenterer - blant annet - badetemperaturer.  
Denne webfrontenden er ment å brukes på samme måte som npm-pakken, ved at man "kan" søke opp sted.  
Men man kan like gjerne liste ut alle badetemperaturer i landet, eller liste ut alle pr. fylke eller kommune.
